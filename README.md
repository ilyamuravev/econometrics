# Удалённость от крупных центров и доходы малого бизнеса

Групповой проект по эконометрике (НИУ ВШЭ). Краснодарский край, 2023 год.

**Исследовательский вопрос.** Различается ли связь расстояния от населённого пункта регистрации до Краснодара с годовыми доходами на одного работника у микро- и малых предприятий продуктовой розницы и автосервиса?

## Как запустить

1. Склонируйте репозиторий и откройте `krasnodar_sme.Rproj` в RStudio — папка проекта сама станет рабочей директорией, `setwd()` не нужен.
2. Запустите по порядку (целиком через Source или построчно):
   1. `scripts/prepare_data_git.R` — очистка, выборка, прямые расстояния, население;
   2. `scripts/road_distances.R` — добавляет расстояния по дорогам.
   Недостающие пакеты установятся автоматически.
3. Готовые таблицы появятся в папке `data/`.

Рабочая папка — корень проекта (её выставляет `krasnodar_sme.Rproj`), а не `scripts/`. После перезапуска `prepare_data_git.R` запустите и `road_distances.R`: первый скрипт пересобирает датасет без дорожных столбцов, второй вернёт их за секунды из `data/road_distances.csv`, без обращения к интернету.

Полный реестр МСП (`panel.csv`, 16,7 ГБ) в репозиторий не входит и для запуска не нужен: скрипт берёт уже вырезанные строки края за 2023 год из `data/panel_kda_2023.csv.gz`. Чтобы собрать вырезку заново из исходника, скачайте набор ИНИД №205, положите `panel.csv` в корень проекта и удалите `data/panel_kda_2023.csv.gz` — скрипт прочитает реестр сам (5–15 минут).

## Выборка

Юридические лица — микро- и малые предприятия Краснодарского края за 2023 год с основным ОКВЭД:

- **47.11\*** — розничная торговля преимущественно пищевыми продуктами в неспециализированных магазинах (продуктовая розница);
- **45.20\*** — техническое обслуживание и ремонт автотранспортных средств (автосервис).

Звёздочка — вместе с подкодами. Оставлены фирмы с положительными доходами, численностью работников больше нуля и координатами; повторные записи одного ИНН за год сведены к последнему состоянию. Итог — 833 фирмы (561 в рознице, 272 в автосервисе) в 144 населённых пунктах.

## Основные переменные итогового датасета

| Переменная | Описание |
|---|---|
| `log_rpw` | Логарифм доходов на одного работника — зависимая переменная |
| `rev_per_worker`, `revenue`, `employees_count` | Доходы на работника, годовые доходы (руб.), среднесписочная численность |
| `industry`, `auto` | Отрасль: `retail` / `auto`; `auto = 1` — автосервис |
| `size`, `small` | Категория МСП: `micro` / `small`; `small = 1` — малое предприятие |
| `dist_krasnodar`, `dist_sochi`, `dist_novorossiysk` | Расстояние по прямой до центра, км |
| `ln_dist_*` | `log(1 + расстояние)` |
| `road_krasnodar`, `road_sochi`, `road_novorossiysk`, `road_nearest` | Расстояние по автодорогам до центра и до ближайшего из трёх, км (OSRM) |
| `ln_road_*` | `log(1 + расстояние по дорогам)` |
| `dist_nearest`, `nearest_center`, `in_center` | Расстояние до ближайшего из трёх центров, его название; `in_center = 1` — фирма в самом центре |
| `settl_population`, `ln_settl_pop` | Численность населения населённого пункта регистрации и её логарифм |
| `settlement_id` | Идентификатор населённого пункта — для кластеризации стандартных ошибок |
| `outlier_1_99` | 1 — доходы на работника вне 1–99 перцентилей своей отрасли (наблюдения не удалены) |
